# Moments — Photo Journal

A responsive, static photo journal with the complete vertical image collection, three practical guides, and the full-video link at the bottom of the homepage.

- Open `index.html` to browse the home page and all 271 locally stored images.
- The guides cover respectful viewing, bra size and fit, and breast development and enlargement.
- Images are stored under `moments-gallery/images/`; all pages work as a static GitHub Pages site without a build step.
