# Moments — Photo Journal

A responsive static photo journal with three practical guides, 271 locally stored images, and six separate video pages.

- `index.html` is the homepage and contains the full vertical collection plus links to all six video pages.
- `videos/01.html` through `videos/06.html` each show the same image collection, an ad placement, and their own TeraBox link at the bottom after a visible wait.
- Advertising scripts run on each video page. The image files remain under `moments-gallery/images/`.
- All pages deploy through the existing GitHub Pages workflow. No build step is required.
